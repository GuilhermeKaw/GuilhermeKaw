<h1>Olá, me chamo Guilherme Kawan 👋</h1>
</div>

<div align="center">
  <h2>🚀 Sobre Mim</h2>
</div>

Estudante de **Análise e Desenvolvimento de Sistemas no SENAI**, focado em transformar conceitos e lógica em aplicações reais e eficientes. 

No desenvolvimento **Front-end**, minha paixão é colocar a mão na massa: pegar o layout e trazê-lo à vida no navegador com precisão, interatividade e fluidez. No **Back-end** e em **Banco de Dados**, gosto de estruturar arquiteturas sólidas utilizando **PostgreSQL** e **SQL Server** — construindo a fundação que serve como o verdadeiro coração de grandes sistemas.

<div align="center">
  <h2>🛠️ Tecnologias & Ferramentas</h2>
</div>

<br/>

- <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/csharp/csharp-original.svg" width="20" height="20" alt="C#"/> **C#**: Linguagem fortemente tipada e orientada a objetos da Microsoft, ideal para construção de APIs escaláveis, regras de negócio robustas e sistemas enterprise.
- <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/javascript/javascript-original.svg" width="20" height="20" alt="JavaScript"/> **JavaScript**: Linguagem dinâmica essencial da web, utilizada para criar interatividade, manipular o DOM e integrar dados no front-end.
- <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/html5/html5-original.svg" width="20" height="20" alt="HTML5"/> **HTML5**: Linguagem de marcação padrão para estruturar e organizar o conteúdo semântico das aplicações web.
- <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/css3/css3-original.svg" width="20" height="20" alt="CSS3"/> **CSS3**: Responsável pela estilização visual, construção de layouts responsivos, animações e refinamento da interface.
- <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/postgresql/postgresql-original.svg" width="20" height="20" alt="PostgreSQL"/> **PostgreSQL / SQL Server**: Sistemas de gerenciamento de banco de dados relacionais (SGBD) focados em alta integridade de dados, otimização de consultas e confiabilidade.
